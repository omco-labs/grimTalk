# Contributing

Improvements to the SKILL.md prompt are welcome — open a PR with before/after examples showing the change.

## How

1. Fork repo
2. Edit `SKILL.md` — or other files
3. Open PR with:
   - **Before:** what say now
   - **After:** what say with change
   - One sentence why change better

> **Note on compress skill:** If you are modifying the compress skill, edit `SKILL.md`, `references/grim-compress.md` or `scripts/` as needed.

Small focused change > big rewrite. Me like simple.
